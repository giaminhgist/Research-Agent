# Reporting standards: which one applies

| Study type | Guideline |
|---|---|
| AI for medical imaging (any task) | CLAIM 2024 update |
| Diagnostic or prognostic prediction model (development/validation) | TRIPOD+AI |
| Diagnostic accuracy study of an AI test | STARD-AI (STARD 2015 when STARD-AI does not fit) |
| Randomized trial of an AI intervention / its protocol | CONSORT-AI / SPIRIT-AI |
| Early clinical evaluation of decision support | DECIDE-AI |
| Systematic review / meta-analysis | PRISMA 2020 (+ PRISMA-DTA for diagnostic accuracy) |
| Risk of bias of prediction-model studies in a review | PROBAST(+AI) |
| Machine-learning reproducibility (general) | NeurIPS/ICML reproducibility checklist |

The writing agent fills in the applicable checklist as a table: item → where it is addressed (section/page) → or "not applicable" with the reason.
